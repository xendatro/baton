- 2026-09-24: Project named "Baton" (handoffs between people and agents). Stack per SPEC.md section 2.
- 2026-09-24: Toolchain pinned to what typescript-eslint supports: TypeScript 6.0 (TS 7 is out, but typescript-eslint 8 requires TS < 6.1). Also on the latest majors: Vite 8, Vitest 5, ESLint 10, React Router 8 (SPEC says 7; its route-object API is unchanged), Drizzle ORM 0.45 (1.0 is still beta), @hono/node-server 2.
- 2026-09-24: Better Auth tables were generated with the Better Auth CLI (`auth generate`, username + emailOTP plugins). `user.theme` is an enum column, NOT NULL, default `'system'`. The auth config must declare it as `{ type: ['system','light','dark'], required: true, defaultValue: 'system', input: false }` and set `advanced.database.generateId` to `newId` (ULIDs).
- 2026-09-24: Author, actor, creator, uploader, resolver, claimer and deleter FKs are nullable with `ON DELETE SET NULL`, so content survives account deletion and shows a "deleted user". `team.owner_id` is `RESTRICT`, because account deletion is blocked while the user owns a team.
- 2026-09-24: The `activity` table has no foreign keys (only indexes), so the append-only audit log outlives purged entities. The per-user security log lives in `activity` rows with `team_id` NULL and `entity_type` `user` or `api_key`.
- 2026-09-24: `attachment.team_id` is nullable, only for `user_avatar` uploads, which belong to no team.
- 2026-09-24: Extra constraints beyond SPEC §4: `status` is unique per (project, name), with a partial unique index allowing one default status per project; `role` allows one `is_everyone` role per team (partial unique); `task_dependency` has a CHECK against self-blocking. Team slugs and project keys are unique only among non-deleted rows (partial unique indexes), so restoring an item whose slug or key was reused is a `conflict`.
- 2026-09-24: `search_index` (FTS5) makes `entity_type` UNINDEXED too (SPEC lists it as indexed), so the word "task" in a query doesn't match every task. Filter types with `entity_type IN (…)`. It uses the `porter unicode61 remove_diacritics 2` tokenizer with `prefix='2 3'` for as-you-type search.
- 2026-09-24: Live events carry `teamId: string | null` plus an optional `userId` (the recipient of personal events), because `me.updated` has no team. For `activity.created`, `parentType`/`parentId` name the entity the activity row is about.
